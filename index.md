# Screen Simulator

A Chrome extension that shows the page you are on in phones, tablets, laptops and desktop monitors, side by side, in realistic frames. It checks the layout, takes screenshots, and has an optional local MCP server so AI agents can drive it.

- [Privacy policy](privacy/)
- MCP server: [`screen-simulator-mcp` on npm](https://www.npmjs.com/package/screen-simulator-mcp)
- Support: musakazim.ay@gmail.com

# Ekran Simülatörü

Bulunduğun sayfayı telefon, tablet, laptop ve monitörlerde gerçekçi çerçevelerle yan yana gösteren bir Chrome eklentisi. Düzeni denetler, ekran görüntüsü alır ve yapay zekâ ajanlarının yönetebilmesi için isteğe bağlı yerel bir MCP sunucusu sunar.

- [Gizlilik politikası](privacy/)
- MCP sunucusu: [npm'de `screen-simulator-mcp`](https://www.npmjs.com/package/screen-simulator-mcp)
- Destek: musakazim.ay@gmail.com
